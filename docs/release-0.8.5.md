# 阿龍学习输入法 0.8.5

本版接续整句翻译修复分支，保留现有 API 模型与凭证。三种翻译短预设完成对照评测，暂未接入设置，也未替换产品提示词。

## 本版行为

- 重复发布相同候选页时复用排版与测量结果；候选内容、注释、译文或富文本样式变化仍触发测量。
- 输入法重新激活时提前启动焦点会话；窗口与延迟按键队列通过非阻塞轮询等待工作线程确认，保留按键顺序和过期会话校验。
- 整句模式下，未选词且只含小写字母的拼音按单独 Shift 原样提交，如 cpu；没有这类缓冲时，Shift 继续切换本次中英文输出。
- Caps Lock 开启时将上述未选词字母提交为大写，后续字母按 Caps Lock 输入；已选中文、带分隔符的拼音和日语组合保持原有处理。
- 沿用整句翻译 HTTP 120 秒、确认等待 125 秒、4096 个 UTF-16 码元分帧提交和 max_tokens=2048。Enter 确认英文、Ctrl+Enter 提交中文。

- 服务显式返回非 stop 的结束原因（含输出截断、内容过滤或未完成状态）时拒绝提交，保留中文原句；兼容省略结束原因的旧接口。

## 提示词评测

模型为 workbuddy-intl/deepseek-v4.1-flash，76 次调用全部完成；72 次计量请求的耗时中位数：原提示词 1.576 秒、日常 1.610 秒、学术 1.584 秒、创作 1.586 秒。本次没有明显提速证据，不能据此保证长期响应速度。

完整输入、逐次译文、参数、请求标识、质量复核和局限见 docs/validation/translation-prompts-2026-10-22.md 及相邻 JSON。测试语料为人工编写，学术句中的数字不是实际研究结果。

## 验证与安装边界

本机未安装可直接使用的 C++ 构建工具，完整编译与测试由 GitHub Actions 完成，包括 TSF x64/Win32、Server、Engine 和 UI 布局测试。发布验证记录另存 docs/validation，只有成功运行和实际产物核验才记为通过。

真实记事本、浏览器、微信和 QQ 的首次切换、持续输入/删除及 CPU 改善仍需安装后人工验收；策略测试和模拟接口不能替代真实宿主性能验收。验收时先重启对应应用，避免旧 DLL 仍驻留。

本地不自动覆盖正在使用的输入法。安装包当前沿用 package-release 工作流的未签名构建路径，不声称具备受信 uiAccess 或真实代码签名。
