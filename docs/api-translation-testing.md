# 0.8.2 API 接口测试说明

本版用于现有 OpenAI 兼容接口的连接与整句翻译测试，功能实现沿用 0.8.1。此次更新同步版本资源、配置说明与发布说明，未加入单次 Enter 等待后自动上屏等尚未实现的交互。

## 配置顺序

1. 打开「设置 → AI 与云联想」，找到「拼音整句翻译成英文（可选）」及对应接口配置。
2. 填写接口提供者给出的 Base URL、访问密钥和实际可用的模型名称。默认地址 `http://127.0.0.1:8317/v1` 只在本机已有对应接口服务时有效；安装输入法不会自动创建这个服务。
3. 使用模型列表和连接测试检查地址、鉴权及模型调用。模型列表可用不代表翻译一定成功，仍要执行下一步的实际短句测试。需要鉴权的服务须填写自己的有效密钥；匿名服务可留空。
4. 开启整句翻译，输入拼音，按空格或数字选择中文，逐词积累一句完整的话。
5. 保持英文翻译输出模式，等待英文预览，再按 Enter 确认英文。如果仍显示翻译中，等待完成后再次确认。

接口路径会规范化为对应的 `/models` 与 `/chat/completions`；不要把提供者的其他业务接口、网页链接或模型名称当作 Base URL。兼容路径以提供者的实际文档为准。

## 当前按键

| 按键 | 当前行为 |
| --- | --- |
| 空格 / 数字 | 有拼音候选时选择中文并积累句子；无待选拼音且英文预览已就绪时，空格可确认英文 |
| Ctrl+Enter | 确认当前英文；尚未就绪时保留中文并提示，完成后需要再次确认 |
| Enter | 提交当前输出：英文模式提交已就绪译文，中文模式提交中文 |
| Shift | 整句翻译开启时切换中文输出 / 英文翻译，保留拼音通道 |
| Ctrl+Space | 使用 Windows 输入法切换 |

这些按键用于向宿主输入框提交文字；应用是否把 Enter 当作“发送消息”取决于应用自身。建议先在空白文本编辑器中测试，再测试聊天窗口。

## 建议先测的句子

- “我今天很高兴。”：检查确实返回英语句子，而非原始拼音或中文。
- “如果明天不下雨，我们就去公园。”：检查否定条件没有反转。
- “我们明天下午三点半见面。”：检查时间没有丢失或改变。

记录成功/失败、耗时和出现问题的应用名称即可；分享故障信息时请隐藏访问密钥，不要上传个人输入文本。

## 范围与限制

- 不包含 HY-MT 翻译模型或 llama.cpp 翻译运行库；不会自动下载翻译模型。
- 完整包中的拼音词库及用于中文候选解码的既有资源属于输入法基础组件，不是本轮已移除的 HY-MT 中译英组件。
- 翻译与 AI 联想当前共用接口和模型配置，各自开关独立；还没有独立的翻译连接配置。
- 地址为 127.0.0.1 只表示连接本机接口，该服务可能继续转发远程模型；请按你配置的服务判断数据去向。
- API 延迟与翻译质量由所选服务和模型决定，本版不承诺 1 秒内完成。
- 尚未完成单次 Enter 等待并自动提交、SentenceAutoCommit 协商以及本轮真实宿主验收；请勿把本版当作 0.9.0 整句交互修复版。
- 安装包为未签名构建，不能据此宣称 uiAccess 已生效。此次发布不会自动替换本机安装版。
