# API 整句翻译测试说明（0.8.3 候选版）

本版将中文选词和英文提交分开。先在「设置 → AI 与云联想」填入 Base URL、可选密钥与模型，查询模型并测试连接，再开启「拼音整句翻译成英文」。匿名接口可以留空密钥；默认地址 http://127.0.0.1:8317/v1 仅在本机已有对应服务时有效。

| 按键 | 行为 |
| --- | --- |
| 空格 / 数字 | 选择中文并继续积累整句，不提交英文预览 |
| Enter | 英文模式确认整句；未就绪则等待并自动提交；中文模式提交中文 |
| Ctrl+Enter | 直接提交中文 |
| Shift | 切换中文输出与英文翻译，保持拼音通道 |
| Backspace | 撤销选词或删除当前拼音 |
| Esc | 取消组合和待自动提交 |
| Ctrl+Space | 保留 Windows 输入法切换 |

等待中继续编辑、切换模式或失焦会撤销待提交，迟到结果不得写入新输入框。失败或超过 5 秒保留中文；Enter 重试。确认键只把文字写到输入框，不会替应用发送消息。

建议先在空白文本编辑器输入「我 / 今天 / 想 / 去 / 图书馆 / 学习 / 英语」，每段按空格，观察中文保持一句。最后按 Enter，应上屏整句英文。再验证否定、时间、数量、快速退格、切换输入框与模型离线。

模型列表和连接测试成功不代表真实输入链路已通过。记录耗时、状态和应用名称；分享故障时隐藏密钥，不上传个人输入正文。

本版使用配置的 API，不包含或下载本机中译英模型。127.0.0.1 可能是远程模型转发入口。翻译与 AI 联想共用接口，开关独立。最近译文仅缓存在内存，不写入词库、输入学习或请求日志。模型的实际服务延迟不由输入法保证。

当前候选构建的验证结果和安装边界见 [0.8.3 候选版说明](release-0.8.3.md)。
