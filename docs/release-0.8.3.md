# 0.8.3 整句翻译候选版

本版修复逐词空格后的提前提交：已选中文保留在同一个组合区，英文始终根据整句重新翻译，空格不会提交英文词语。

## 使用方式

1. 在「设置 → AI 与云联想」开启「拼音整句翻译成英文」，填入自己的接口、密钥与模型；不需要开启 AI 联想。
2. 拼音逐字或逐词输入，空格或数字选择中文，继续输入下一段。候选窗同时显示中文原句、英文预览与状态。
3. 输入完整一句后按 Enter。译文已就绪则立即上屏；未完成则等待，完成后自动上屏，无须再次按键。这个 Enter 只提交文字，不替应用发送消息。
4. Ctrl+Enter 可直接提交中文。单按 Shift 切换中文输出与英文翻译，拼音通道保持开启。
5. Backspace 撤销选词，Esc 取消。等待时继续编辑、切换模式或离开输入框都会撤销自动提交；失败或等待超过 5 秒保留中文，Enter 可以重试。
6. 超出固定文本协议容量时提示分句，不能截断上屏。

翻译通过配置的 API 接口完成，不下载或启动 HY-MT、llama.cpp 等本机翻译组件。127.0.0.1 可能是远程模型转发入口。

## 性能与验证边界

翻译请求采用 200 ms 防抖，Enter 会跳过防抖；新句子取消旧请求，不排队逐词翻译。最近译文只缓存在内存，最多 32 项、64 KiB。整句模式不再请求候选逐词释义，模型完成通知也不再重复广播输入配置。

截图所示 cn/deepseek-v4.1-flash 接口的固定测试句完整返回约 1.9–2.3 秒；这是接口测试值，不能保证 1 秒完成，也不能当作实际宿主按键延迟。模型速度、输入引擎查询速度与宿主绘制速度需要分别验证。

自动提交使用协商能力 SentenceAutoCommit；Enter 先得到等待确认，模型结果携带原始请求编号。TSF 在所属线程的编辑会话内重新核对焦点、组合、重置代、请求和光标，再提交现有组合。旧 DLL 不支持该能力时会显示更新提示。

CI、HTTP 假服务回归与配置模型测试不替代 Win32、Chromium、聊天窗口的实际宿主验收。候选包需完成审阅并取得用户明确安装授权，才能替换本机版本。

安装器的程序目录现遵守 /DIR 参数，后台、快捷方式与登录任务同步使用所选位置；TSF DLL 仍按 Windows 要求注册到系统目录。
